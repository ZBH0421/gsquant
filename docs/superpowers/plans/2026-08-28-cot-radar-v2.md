# COT Radar V2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make COT Radar V2 auditable for freshness, ES/NQ comparison, state transitions, and historical validation while preserving the existing static deployment and market scope.

**Architecture:** Extend the existing Python-derived artifact contract instead of adding runtime services. Compute all comparison/state/freshness rules in Python, keep thresholds in YAML, and make the React UI a deterministic renderer of those artifacts.

**Tech Stack:** Python 3.11, pandas, gs-quant, pytest, Ruff, mypy, React 19, TypeScript, Vitest, Plotly, Vite, GitHub Actions/Pages.

**Spec:** `docs/superpowers/specs/2026-08-28-cot-radar-v2-design.md`

## Global Constraints

- ES and NQ only; CFTC TFF Futures Only dataset `gpe5-46if`.
- Leveraged Funds primary; Asset Managers comparison; Dealer/Other objective context.
- SPY/QQQ are explicit price proxies only.
- No runtime LLM, trading advice, look-ahead bias, secrets, or raw price redistribution.
- Preserve timezone-safe CFTC report calendar dates.
