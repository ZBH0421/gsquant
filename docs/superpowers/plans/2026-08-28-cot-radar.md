# COT Radar Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver a deployed ES/NQ CFTC positioning and reversal-risk dashboard with lookahead-safe analytics, deterministic narratives, historical validation, and automated weekly refresh.

**Architecture:** A Python package retrieves and validates official CFTC TFF Futures Only data plus SPY/QQQ weekly proxy prices, computes versioned signals and static artifacts, and a React/Vite client renders those artifacts without a backend. GitHub Actions runs tests, refreshes data, and deploys the static site to GitHub Pages.

**Tech Stack:** Python 3.11, pandas, NumPy, httpx, PyYAML, GS Quant, pytest, Ruff, mypy; React 19, TypeScript, Vite, Plotly, Vitest, Testing Library; GitHub Actions and GitHub Pages.

**Spec:** `docs/superpowers/specs/2026-08-28-cot-radar-design.md`

## Global Constraints

- Analyze only ES and NQ in the MVP.
- Use CFTC dataset `gpe5-46if`, TFF Futures Only.
- Use Leveraged Funds for the primary state and Asset Managers for comparison.
- Use SPY/QQQ only as clearly labeled price-confirmation proxies.
- Exclude the current observation from 156-week percentile and z-score windows; require 52 prior observations.
- Keep deterministic analysis separate from user-authored subjective notes.
- Do not use a runtime LLM or emit trade instructions.
- Publish only derived price information, not complete raw price files.
- Keep all feature code under `projects/cot-radar`.
- Target `https://zbh0421.github.io/gsquant/cot-radar/`.
